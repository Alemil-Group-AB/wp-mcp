# wp-mcp

MCP tool for creating, editing, and retrieving posts from your WordPress website.

## Project status
This repo is the starting point for an open source project that will make it
possible to run a WordPress MCP on any WordPress site. The first step is to
clarify goals, functionality, and how to get started.

## Goals
- Make it easy to install and run a WordPress MCP as a plugin.
- Provide clear OAuth support for secure access.
- Offer a simple, step-by-step guide for setup and operation.

## Planned features (MVP)
- MCP endpoint for creating, reading, and updating posts.
- OAuth 2.0 authentication flow (e.g., Authorization Code).
- Configuration page in the WordPress admin.
- Documentation and client call examples.

## Getting started (overview)
1. Clone the repo.
2. Build/package the plugin.
3. Install it in WordPress (via admin or zip).
4. Configure OAuth in the WordPress admin.
5. Connect an MCP client and start using endpoints.

> **Note:** In the next step, we will add real plugin code, the OAuth flow,
> and a complete installation guide.
