# AGENTS

## Scope
These guidelines apply to the entire repository unless a more specific
`AGENTS.md` exists in a subdirectory.

## Working agreements
- Keep all repository content in English.
- Prefer small, focused changes with clear commit messages.
- Update documentation when behavior, configuration, or setup steps change.

## Code style
- Follow existing project conventions where present.
- Avoid introducing try/catch blocks around imports.

## Testing
- Run relevant tests when you change behavior.
- If tests are not run, state that explicitly with the reason.

## Pull requests
- Summaries should be concise and user-facing.
- Include testing details in the PR body.
